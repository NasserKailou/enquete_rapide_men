⚡ INSTALLATION RAPIDE (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════

ÉTAPE 1 : Décompresser
────────────────────────────────────────────────────────────────────────
unzip enquete_education_niger.zip
cd enquete_education_niger

ÉTAPE 2 : Créer la base de données
────────────────────────────────────────────────────────────────────────
mysql -u root -p < database.sql

Ou via phpMyAdmin :
  1. Créer la base : enquete_rentree_niger
  2. Importer : database.sql

ÉTAPE 3 : Configurer la connexion
────────────────────────────────────────────────────────────────────────
Éditer config.php :

  define('DB_HOST', 'localhost');
  define('DB_NAME', 'enquete_rentree_niger');
  define('DB_USER', 'root');
  define('DB_PASS', 'votre_mot_de_passe');

ÉTAPE 4 : Déployer
────────────────────────────────────────────────────────────────────────
Copier tous les fichiers dans votre répertoire web :

  cp -r * /var/www/html/enquete/

ÉTAPE 5 : Tester
────────────────────────────────────────────────────────────────────────
Ouvrir dans le navigateur :
  http://localhost/enquete/
  ou
  http://votre-domaine.ne/enquete/
